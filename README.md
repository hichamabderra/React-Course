# Modern React Engineering Course

This repository is a progressive, production-minded React course built around **Northstar Commerce**, a SaaS commerce storefront and admin capstone. The course emphasizes state ownership, current React APIs, accessible interaction, secure API boundaries, testing, and measured production trade-offs—not isolated syntax or a Todo app.

## Start here

1. Read the [Course Guide](course/README.md) for the philosophy, verified stack, learning outcomes, roadmap, and capstone architecture.
2. Read the [Verified Stack and Selection Notes](course/verified-stack.md) before installing dependencies.
3. Build [Module 1 — Project Foundation](course/modules/01-project-foundation.md) from a clean Vite starter.
4. Use the [Official Documentation Map](course/official-documentation-map.md) to find current primary-source references by module.

## Capstone references

- [Backend Contract and Security Flows](course/capstone/backend-contract.md) — HTTP/API conventions, endpoint shapes, session models, and login/refresh/logout/RBAC diagrams.
- [Final Challenge PRD](course/capstone/final-challenge-prd.md) — requirements only; learners design and review the architecture before implementation.

## Course progress

The complete 21-module course is documented as separate Markdown lessons, alongside the version snapshot, capstone API/security contract, and final requirements-only challenge. Each lesson has a build goal, first-principles explanations, trade-offs, debugging examples, exercises, production tips, official docs, a summary, and readiness criteria.

The stack and package versions are a **September 28, 2026** verification snapshot. Check the official docs and compatibility notes again before adopting a later library version.
